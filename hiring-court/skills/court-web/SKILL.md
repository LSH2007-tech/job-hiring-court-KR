# 취업 재판 시작 (웹 화면)

`취업-재판` 스킬을 화면으로 쓰는 로컬 웹앱이다. 서버는 이 플러그인의 `web/server.py`이고, 판단은 이 PC에 로그인된 Claude Code가, 세기와 검사는 `court_tool.py`가 한다. 사용자의 구독 한도에서 돌며, 다른 서버로 자료를 보내지 않는다.

## 여는 순서
1. 이 스킬 폴더(스킬을 불러올 때 표시되는 기본 경로)에서 두 단계 위가 플러그인 폴더다. 서버 파일은 `<플러그인 폴더>/web/server.py`.
2. Bash(또는 PowerShell)에서 백그라운드로 실행한다: `python "<플러그인 폴더>/web/server.py"`. `python`이 없으면 `python3`, `py -3` 순서로 시도한다. 브라우저가 자동으로 열린다.
3. 서버가 출력한 주소(`http://localhost:8765/?k=<열쇠>`)를 그대로 사용자에게 알리고, "이 Claude Code 창을 닫으면 화면도 꺼진다"는 것을 한 줄로 알린다. 열쇠는 켤 때마다 바뀌고, 열쇠 없는 주소(`http://localhost:8765/`)로는 열리지 않는다. 주소를 직접 지어내지 말고 서버 출력에서 읽는다. 8765 포트가 이미 쓰이고 있으면 `--port 8766`처럼 바꿔 연다.
4. 서버가 "hiring-court 스킬을 찾지 못했다"고 하면 플러그인 설치가 깨진 것이니 플러그인 업데이트를 안내한다.

## 사용자에게 알려 줄 것
- 단계마다 Claude를 부르므로 1~3분씩 걸린다.
- 재판 한 번에 Claude를 10번 안팎 부른다. Pro 요금제(Opus 5.5, 높은 연산 수준)에서 5시간 사용 한도의 약 20~30%를 쓰니, 시작 전에 남은 사용량을 확인하라고 알린다.
- 지원자 기록은 대문에서 '지원자 파일 넣기'(이력서, 경력기술서, 기존 자소서) 또는 'Notion 연동'으로 넣는다.
- Notion 연동은 Claude Code에 노션이 `notion`이라는 이름으로 등록되어 있어야 한다. 화면이 안내하는 대로 터미널에서 `claude mcp add --transport http --scope user notion https://mcp.notion.com/mcp`와 `claude mcp login notion`을 한 번 실행하면 된다. 웹앱은 노션을 읽기만 한다.
- 공고는 캡처 이미지, 파일(PDF, Word), 본문 붙여넣기 세 가지로 받는다. 링크는 받지 않는다.
- 파일 읽기 품질을 위해 `python -m pip install "markitdown[pdf,docx,pptx,xlsx]"`를 권한다.
- 재판 기록은 사용자가 고른 폴더에 저장된다(기본 `문서/취업재판`). 작업 중 파일은 `~/.hiring-court/`에 있다.

## 하지 않는 것
- 이 스킬은 화면을 여는 일만 한다. 대화 안에서 재판을 진행하려면 `취업-재판` 스킬을 쓴다.
- 서버를 인터넷에 공개하지 않는다(127.0.0.1에서만 듣는다). 열쇠가 든 주소를 다른 사람에게 보내거나 다른 기기에서 열게 하지 않는다.
