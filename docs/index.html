English summary

어떻게 진행되나요

0공고 접수

링크, 캡처 이미지, PDF, 붙여넣기 중 하나로 공고를 넣으면 서기가 정리하고 이해한 내용을 보여 줍니다.

1재판부와 자기소개서

공고와 웹 조사로 이 회사에 맞는 배심원 세 명을 세우고, 자기소개서를 쓰거나 파일로 넣습니다.

2공방

지원자 탈락 위원과 합격 위원이 채팅하듯 주고받습니다.

3배심 표결

인사담당자, 임원진, 실무 담당자가 서로의 표를 보지 않고 투표하고, 합격 원인과 탈락 원인을 냅니다.

4판결과 조언

서류 예측 %, 인정된 탈락 사유, 합격 조건, 그리고 내 경험으로 어떻게 고치면 되는지 알려 줍니다.

5기록과 재심

판결문, 조언, 수정본을 내 PC에 저장하고, 고친 자소서로 재심을 열 수 있습니다.

준비물

  • Claude 구독과 Claude Code (설치하고 로그인되어 있어야 합니다). 재판은 내 구독 한도 안에서 돌아가고, 따로 결제하는 것은 없습니다.
  • Python 3.10 이상
  • 선택: 노션. 이력과 자소서가 노션에 있으면 버튼 한 번으로 연결해 읽어 옵니다(읽기 전용).

설치 (3단계)

1플러그인 추가

Claude Code 입력창에 아래를 입력합니다.

/plugin marketplace add LSH2007-tech/job-hiring-court-KR
2설치

이어서 아래를 입력합니다.

/plugin install hiring-court@lsh-skills
3열기

Claude Code에 이렇게 말하면 브라우저에 화면이 열립니다.

취업재판 웹 열어 줘

PDF와 Word 파일을 더 정확히 읽으려면 한 번만 실행해 주세요: python -m pip install "markitdown[pdf,docx,pptx,xlsx]"

자주 묻는 질문

비용은 누가 내나요?

각자 자기 Claude 구독으로 돌아갑니다. 운영 서버가 없어서 추가 요금이나 가입이 없습니다. 재판 한 건에 Claude를 8번쯤 부르므로 구독 한도를 그만큼 씁니다.

내 이력서와 자소서는 어디로 가나요?

화면과 서버는 내 PC 안에서만 돕니다(주소가 localhost입니다). 자료는 내 PC의 폴더에 저장되고, 분석을 위해 Claude에게만 전달됩니다.

노션이 없어도 되나요?

됩니다. 이력서, 경력기술서, 기존 자소서 파일(PDF, Word, 한글 hwpx)을 넣으면 같은 방식으로 분석합니다.

대화창에서도 쓸 수 있나요?

네. Claude Code에서 "서류 재판 열어 줘"라고 하면 화면 없이 대화로 진행합니다.

예측 %는 얼마나 믿을 수 있나요?

실제 합격률이 아니라 모의 배심의 추정입니다. 여러 회사를 견주는 상대 비교와, 무엇을 고칠지 찾는 용도로 써 주세요.

English summary

Mock Hiring Court is a Claude Code plugin that puts a Korean job application (자기소개서) on trial against a job posting. A prosecutor and a defender argue, three jurors (HR, executive, hiring manager) vote independently, and a judge returns a verdict with concrete revision advice.

It runs entirely on your own machine and your own Claude subscription: a small local web server (localhost) drives Claude Code in headless mode. There is no hosted service and no API key.

Install: /plugin marketplace add LSH2007-tech/job-hiring-court-KR, then /plugin install hiring-court@lsh-skills, then ask Claude Code to open the web screen ("취업재판 웹 열어 줘"). Requires Claude Code (logged in) and Python 3.10+.

Language: the interface, prompts and scoring rules are in Korean because the tool targets Korean hiring documents.
