0공고 접수

캡처 이미지, 파일(PDF, Word), 본문 붙여넣기 중 하나로 공고를 넣으면 서기가 정리하고 이해한 내용을 보여 줍니다.

1재판부와 자기소개서

공고와 웹 조사로 이 회사에 맞는 배심원 세 명을 세우고, 자기소개서를 쓰거나 파일로 넣습니다.

2공방

지원자 탈락 위원과 합격 위원이 채팅하듯 주고받습니다.

3배심 표결

인사담당자, 임원진, 실무 담당자가 서로의 표를 보지 않고 투표하고, 합격 원인과 탈락 원인을 냅니다.

4판결과 조언

서류 예측 %, 인정된 탈락 사유, 합격 조건, 그리고 내 경험으로 어떻게 고치면 되는지 알려 줍니다.

5기록과 재심

판결문, 조언, 수정본을 내 PC에 저장하고, 고친 자소서로 재심을 열 수 있습니다.

필요한 것과 동작 방식

쓰는 방법이 두 가지입니다. 어느 쪽이든 운영 서버가 없어서, 내 서류는 나와 Claude(Anthropic)만 봅니다.

브라우저에서 바로Claude Code 플러그인
설치없음. 이 사이트에서 바로 엽니다Claude Code(로그인) + Python 3.10 이상
필요한 것Claude API 키 (Claude Console에서 발급, 결제 수단 등록)Claude 구독(Pro 이상)과 Claude Code
비용사용한 만큼 내 API 계정에서 나갑니다. 재판 한 건에 Claude를 8번쯤 부릅니다내 구독 한도 안에서 돕니다. 추가 결제 없음
어디서 도나내 브라우저가 Claude API를 직접 부릅니다. API 키는 이 브라우저에만 저장됩니다내 PC의 작은 서버(localhost)가 내 Claude Code를 실행합니다
지원자 기록파일 넣기(이력서, 경력기술서, 기존 자소서)파일 넣기 또는 노션 연동(버튼 한 번 로그인, 읽기 전용)
기록 저장ZIP 파일로 내려받기내가 고른 폴더에 저장
잘 맞는 사람Claude Code를 쓰지 않고 바로 써 보고 싶은 사람Claude 구독이 있고 자주 쓸 사람

한 번의 재판이 도는 방식

0 공고 접수 공고를 정리하고 숨은 지시문(AI 심사기를 겨냥한 문장)을 걸러냄
1 재판부 공고와 웹 조사로 인사·임원·실무 배심원의 성격과 관점을 세움 → 자소서 접수
2 공방 탈락 위원과 합격 위원이 진술마다 800자 안에서 다툼
3 표결 배심원 셋이 서로의 표를 보지 않고 동시에 투표
4 판결과 조언 서류 예측 = 인사와 실무의 평균 → 판사 선고 → 고칠 점
5 전달 판결문, 조언, 수정본, 기록 → 6 재심 또는 제출

판단은 Claude가, 숫자는 코드가 셉니다. 글자 수, 직무 일치도(직접 해 본 일, 비슷한 경험, 비어 있는 곳), 표 검사와 집계는 모델이 아니라 코드가 계산합니다. 두 방식 모두 같은 재판 규칙 문서(SKILL.md)를 읽습니다.

자주 묻는 질문

비용은 누가 내나요?

사용자 본인이 냅니다. 브라우저 방식은 내 API 키로 쓴 만큼, Claude Code 방식은 내 구독 한도 안에서 돕니다. 운영자가 따로 받는 돈이나 가입은 없습니다.

Claude Code 없이 쓸 수 있나요?

네. 위의 '브라우저에서 바로 시작'을 누르고 Claude API 키를 넣으면 설치 없이 씁니다. Claude 구독(Pro, Max)은 Claude 앱과 Claude Code 안에서만 쓸 수 있어서, 웹사이트에서는 API 키가 필요합니다.

내 이력서와 자소서는 어디로 가나요?

운영 서버가 없습니다. 브라우저 방식은 내 브라우저에서 Anthropic API로만, Claude Code 방식은 내 PC에서 Claude로만 전달됩니다. 기록은 내 PC에 저장됩니다.

고치거나 가져다 써도 되나요?

네. MIT 라이선스로 공개되어 누구나 쓰고, 고치고, 나눌 수 있습니다. GitHub 저장소에 이슈와 풀 리퀘스트를 환영합니다.

노션이 없어도 되나요?

됩니다. 이력서, 경력기술서, 기존 자소서 파일(PDF, Word, 한글 hwpx)을 넣으면 같은 방식으로 분석합니다.

대화창에서도 쓸 수 있나요?

네. Claude Code에서 "서류 재판 열어 줘"라고 하면 화면 없이 대화로 진행합니다.

예측 %는 얼마나 믿을 수 있나요?

실제 합격률이 아니라 모의 배심의 추정입니다. 여러 회사를 견주는 상대 비교와, 무엇을 고칠지 찾는 용도로 써 주세요.

English summary

Mock Hiring Court is a Claude Code plugin that puts a Korean job application (자기소개서) on trial against a job posting. A prosecutor and a defender argue, three jurors (HR, executive, hiring manager) vote independently, and a judge returns a verdict with concrete revision advice.

Two ways to run it, no hosted server either way. (1) Browser app: no install; your browser calls the Claude API with your own API key (pay per use). (2) Claude Code plugin: a local server (localhost) drives your own logged-in Claude Code, so it runs on your Claude subscription and can read your Notion (read-only).

Plugin install: /plugin marketplace add LSH2007-tech/job-hiring-court-KR, then /plugin install hiring-court@lsh-skills, then ask Claude Code to open the web screen ("취업 재판 시작"). Requires Claude Code (logged in) and Python 3.10+.

Language: the interface, prompts and scoring rules are in Korean because the tool targets Korean hiring documents.
